Checkpoint contract

Long jobs should call platform_checkpoint() periodically (it is defined in the execution prelude): it snapshots CHECKPOINT_PATH (default /content/checkpoints/<job_id>) to the platform volume. If Colab reclaims the runtime mid-run, the run is marked RECLAIMED and a new attempt is auto-enqueued — the checkpoint is re-uploaded to the fresh runtime before your code runs again. No synthetic keep-alive is ever sent; reclaimed runtimes are expected and handled.
